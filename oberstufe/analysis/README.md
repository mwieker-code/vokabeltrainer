# Analysis Skills

Original English-language definitions, contexts, examples, explanations and model analyses. The source worksheet informed the topic selection; its text and examples are not reproduced.

- 12 devices, 36 contextual examples, 12 term-recall questions, 12 distinction questions, 36 identification questions and 36 function questions.
- Up to six initial questions per round. At most one additional attempt per mistake.
- Separate latest-answer counts for terminology, recognition and function. Due questions are prioritised; successful questions are scheduled 1–7 days ahead.
- Four mini-analysis tasks with optional writing support, local autosave, model answers after a first attempt and a self-assessment checklist. No automated writing grade.
- A separate `vt:analysis:v1` storage key preserves the vocabulary trainer's existing records. Backup includes drafts and checklists. Import merges records and replaces matching entries with those from the imported backup.
- No external AI service or paid runtime dependency.

Run `npm test` at the repository root for the vocabulary and analysis suites. Layout and speech still need checks on real student devices. Narrative techniques and teacher reporting are not included in this version.
